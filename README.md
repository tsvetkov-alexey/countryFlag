# Country Flag

Приложение для macOS 13 и новее, которое показывает в строке меню флаг страны вашего публичного IP. Сборка работает на Mac с Apple Silicon и Intel.

Откройте `CountryFlag.app` в Finder двойным щелчком. Нажмите на флаг, чтобы увидеть страну, скопировать IP, обновить данные или выйти из приложения.

Country Flag проверяет адрес при изменении сетевого подключения и каждые 30 секунд. При использовании VPN или прокси отображается страна того IP, с которого приложение обращается к сервису. Приложение показывает глобус, пока определяет страну при запуске или после смены сети, а также если сервис не вернул код страны.

Для определения страны приложение делает HTTPS-запрос к [Country.is](https://country.is/). Сервис видит публичный IP этого запроса и возвращает его вместе с кодом страны.

## Сборка

Для сборки нужны Command Line Tools для Xcode со Swift 6. Запустите скрипт в этом каталоге.

```sh
bash build.sh
```

Приложение `CountryFlag.app` появится рядом со скриптом.
